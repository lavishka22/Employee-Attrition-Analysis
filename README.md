# HR Analytics Dashboard using Power BI

## Overview
This project is an interactive HR Analytics Dashboard developed using Power BI to analyze employee attrition, salary trends, workforce demographics, and job role performance. The dashboard provides meaningful business insights through dynamic visualizations and KPI metrics.

---

## Tools & Technologies
- Power BI
- DAX
- Excel / CSV
- Data Visualization

---

## Features
- Employee attrition analysis
- Interactive filters and slicers
- KPI cards for HR metrics
- Attrition analysis by:
  - Age
  - Salary
  - Education
  - Gender
  - Job Role
- Dynamic charts and visualizations

---

## Key Insights
- Highest attrition observed among employees aged 26–35
- Laboratory Technicians and Sales Executives showed maximum attrition
- Most attrition occurred in lower salary ranges
- Department-wise analysis helps identify workforce trends
